## Title
Machine Learning Engineer Intern - Applied AI/ML Co-op

## Company 
[Sway AI](https://www.linkedin.com/company/swayai/)

## Location
Burlington (Boston), Massachusetts, USA    

## Duration
July 2023 - December 2023

## Overview
Developed ML capabilities for Sway AI's cloud-agnostic no-code AI platform, enabling business users to build, train, and deploy production ML models without coding across AWS, GCP, and Azure environments.

**Key Contributions:**
- Built and validated ML models for diverse use cases: classification, regression, time-series forecasting, NLP, and computer vision
- Developed scalable implementations handling big-data workloads with distributed processing
- Created deployment pipelines enabling one-click model deployment to multiple cloud providers (AWS SageMaker, GCP Vertex AI, Azure ML)
- Implemented automated model validation and testing frameworks ensuring production-ready quality

**Platform Impact:** Contributed to no-code platform serving 50+ enterprise customers building ML solutions for demand forecasting, customer churn prediction, sentiment analysis, and document processing use cases.

**Technical Environment:** Python, TensorFlow, PyTorch, Scikit-learn, Docker, Kubernetes, AWS (S3, SageMaker, Lambda), GCP (Vertex AI, Cloud Storage), Azure ML
