### Overview

Real-time image processing application applying visual effects to both static images and live camera feed at 30 FPS. Explores RGB, HSV, and grayscale conversions, convolution operations, edge detection, and efficient frame-by-frame memory management through a real-time video processing pipeline. Supports both static image input and live webcam feed.

### Features

- **Negative Effect:** Pixel-wise inversion across all channels
- **Blur Filters:** Gaussian and box blur with configurable kernel sizes
- **Cartoonization:** Edge-preserving bilateral filter + quantized color palette
- **Edge Detection:** Sobel operators for gradient-based edge extraction
- **Interactive Controls:** Keyboard shortcuts to toggle effects, save processed frames

## Technologies

C++, OpenCV
