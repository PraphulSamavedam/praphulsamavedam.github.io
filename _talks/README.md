# Academic Talks Collection

**Status:** Hidden for professional portfolio (preserved for easy restoration)

This directory contains conference talks, presentations, and speaking engagements. The content is currently **not displayed** on the public website to maintain a professional engineering portfolio focus.

## Why Hidden?

The site currently emphasizes:
- Software engineering experience at Amazon AGI, Nvidia, UBS, BNY Mellon
- Technical projects and ML/AI implementations
- Production engineering skills and distributed systems expertise
- Professional achievements and competition wins

Academic talks are preserved here for future use or restoration if needed.

## Restoring This Content

To make talks visible again:

1. Uncomment the talks collection in `_config.yml` (around line 208)
2. Uncomment the talks defaults in `_config.yml` (around line 283)
3. Uncomment "Talks" in `_data/navigation.yml`
4. Uncomment the talks archive page `_pages/talks.html`

## Contents

This directory contains markdown files for individual talks and presentations with metadata including:
- Talk titles and venues
- Presentation dates and locations
- Conference names and events
- Slides and video links
- Talk descriptions and abstracts

**Note:** The talks collection has `output: false` by default, meaning individual talk pages were not generated even when active. Only the talks archive page listed them.
