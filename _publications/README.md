# Academic Publications Collection

**Status:** Hidden for professional portfolio (preserved for easy restoration)

This directory contains research publications and academic papers. The content is currently **not displayed** on the public website to maintain a professional engineering portfolio focus.

## Why Hidden?

The site currently emphasizes:
- Software engineering experience at Amazon AGI, Nvidia, UBS, BNY Mellon
- Technical projects and ML/AI implementations
- Production engineering skills and distributed systems expertise
- Professional certifications and industry achievements

Academic publications are preserved here for future use or restoration if needed.

## Restoring This Content

To make publications visible again:

1. Uncomment the publications collection in `_config.yml` (around line 206)
2. Uncomment the publications defaults in `_config.yml` (around line 274)
3. Uncomment "Publications" in `_data/navigation.yml`
4. Uncomment the publications archive page `_pages/publications.md`
5. Consider uncommenting the research section in `_pages/about.md`

## Contents

This directory contains markdown files for individual publications with metadata including:
- Paper titles and venues
- Publication dates
- Authors and citations
- Links to papers and code repositories
