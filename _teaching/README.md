# Academic Teaching Collection

**Status:** Hidden for professional portfolio (preserved for easy restoration)

This directory contains teaching and tutoring experiences, including graduate-level teaching assistant positions and academic instruction roles. The content is currently **not displayed** on the public website to maintain a professional engineering portfolio focus.

## Why Hidden?

The site currently emphasizes:
- Software engineering experience at Amazon AGI, Nvidia, UBS, BNY Mellon
- Technical projects and ML/AI implementations
- Production engineering skills and distributed systems expertise
- Professional leadership (GDSC President, though Teaching Assistant role is mentioned on homepage)

Teaching content is preserved here for future use or restoration if needed.

## Restoring This Content

To make teaching experiences visible again:

1. Uncomment the teaching collection in `_config.yml` (around line 202)
2. Uncomment the teaching defaults in `_config.yml` (around line 265)
3. Uncomment "Teaching" in `_data/navigation.yml`
4. Uncomment the teaching archive page `_pages/teaching.html`

## Contents

This directory contains markdown files for individual teaching experiences with metadata including:
- Course titles and institutions
- Teaching dates and semesters
- Student counts and course levels
- Topics covered and responsibilities
- Course materials and syllabi
